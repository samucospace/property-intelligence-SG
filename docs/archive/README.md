# Historical documentation archive

Organized 8 October 2026. This index is a catalogue, not a fourth source of operating requirements.

Current guidance lives in [AGENTS.md](../../AGENTS.md), [PRODUCT_SPEC.md](../PRODUCT_SPEC.md), and [OPERATIONS.md](../OPERATIONS.md). Earlier status/approval/completion statements describe their recorded dates, including statements later corrected. Archived scripts and operating commands are not current instructions.

## Layout and preservation

- `remediation-2026-10/`: original go-live reports, phase plans/contracts/runbooks, older product/design specifications, deployment reports and a snapshot of the previous root README.
- `changes-2026-10/`: smaller dated repair and UX reports.
- Current [usability research plan](../research/USER_TESTING_PLAN.md) remains outside the historical archive. Its original body was preserved.
- `audit/` remains in its original repository location. Qualification JSON evidence was not edited or normalized.

Archived Markdown bodies were preserved except for adding this historical status banner and repairing navigation links. The consolidation verification artifact records original/final hashes and checks: [documentation consolidation](../../audit/2026-10-08/documentation-consolidation.json). Git retains the original paths/content and movement history.

## Local-only history

Six pre-existing internal review documents remain ignored by Git in `docs/archive/private-local/`: `TECHNICAL_REVIEW.md`, `REMEDIATION_PLAN.md`, `POST_REMEDIATION_REPORT.md`, `POST_REMEDIATION_REVIEW.md`, `POST_REMEDIATION_VERIFICATION_REPORT.md`, and `SECURITY_AND_RESILIENCE_REVIEW.md`.
